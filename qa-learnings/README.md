# QA Learnings Ledger — Mandate

This ledger captures project-specific QA rules, regression checks, decisions,
and risk surfaces for the Mandate project. It is initialized by the
`production-ready-development` skill during the first project takeover audit.

## Purpose

- **Regression rules** — learned from human-found or CI-caught defects.
- **Project-specific QA conventions** — things this project needs beyond the
  generic skill.
- **Decision/change records** — what changed, why, what was affected.
- **Known-risk surfaces** — areas warranting deeper inspection than default.

## Files

- `regression-rules.md` — accumulated regression rules.
- `decisions.md` — decision/change ledger.
- `risk-surfaces.md` — project-specific high-risk areas.
